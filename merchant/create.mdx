---
title: "Create Merchant & Generate API Key"
---

A merchant represents your business within Coinom.

You need to create a merchant before you can accept payments or generate an API key.

---

## Steps to Create a Merchant

Follow these steps to create a new merchant:

1. Log in to your Coinom account.
2. From the main menu, click **Merchants**.
3. Click **Create New Merchant**.
4. Enter a **Merchant Title** and your **Website URL**.
5. Click **Create Merchant**.

Your merchant will be created instantly and appear in the **Merchants** list.

---

## Generate API Key

After creating your merchant, you must generate an API key before you can integrate Coinom with your website or application.

To generate your API key:

1. On merchants page, in the **Merchant Information** section, click **Generate API Key**.
2. In the side panel that opens, click **Generate New API Key**.
3. Your API key will be generated and displayed.

> **Important:** Your API key is displayed only once for security reasons. Be sure to copy and store it in a secure location before closing the panel.

---

## Regenerate API Key

If you lose your API key, it cannot be viewed again.

To generate a new API key:

1. In the **Merchant Information** section, click **Regenerate API Key**.
2. Confirm the action.
3. A new API key will be generated and displayed.

> **Important:** The new API key is also displayed only once. Be sure to copy and store it securely before closing the panel.
>
> **Note:** Regenerating your API key immediately invalidates the previous one. Be sure to update your website or application with the new API key to avoid authentication errors.
