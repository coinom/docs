## Installation

1. Download the Coinom PrestaShop module ZIP file.
2. Log in to your PrestaShop Back Office.
3. Navigate to **Modules → Module Manager**.
4. Click **Upload a Module**.
5. Select the Coinom module ZIP file.
6. Wait for the installation to complete.

## Configuration

<Tip>
  Before configuring the module, create a merchant and copy the API Key.

  [Create Merchant & Access API Key](https://docs.coinom.com/merchant/create)
</Tip>

After installing the Coinom module:

1. Navigate to **Modules → Module Manager**.
2. Locate the **Coinom** module.
3. Click **Configure**.
4. Enter your **Coinom API Key**.
5. Click **Save Changes**.

## You're Ready

Your PrestaShop store is now configured to accept cryptocurrency payments through Coinom.

Customers will see Coinom as a payment method during checkout, and orders will be updated automatically once payments are confirmed.
