## Overview

The Coinom WooCommerce plugin allows merchants to accept cryptocurrency payments through Coinom.

## Installation

<Tabs>
  <Tab title="WordPress Admin">
    1. Download the Coinom WooCommerce plugin ZIP file.
    2. Navigate to **Plugins → Add New Plugin**.
    3. Click **Upload Plugin**.
    4. Select the ZIP file.
    5. Click **Install Now**.
    6. Activate the plugin.
  </Tab>
  <Tab title="Manual Installation">
    1. Extract the plugin ZIP file.
    2. Upload the plugin folder to `/wp-content/plugins/`.
    3. Activate the plugin from the WordPress Plugins page.
  </Tab>
</Tabs>

<br />

## Configuration

<Info>
  Before configuring the plugin, create a merchant and obtain your API Key.

  [Create Merchant & Access API Key](https://docs.coinom.com/merchants/create)
</Info>

After activating the plugin, open the Coinom gateway settings.

### API Key

Generate an API Key from your Coinom Dashboard and paste it into the plugin settings.

### Merchant

Select the merchant that should receive incoming payments.

### Return URL

Customers are automatically redirected back to your store after successful payment.

### Payment Verification

Coinom verifies payments server-side before updating the WooCommerce order status.

<Tip>
  Create and manage your API Keys from the Merchant page in your Coinom account.

  [Login to Coinom](https://app.coinom.com/login)
</Tip>
