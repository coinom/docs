## Installation

1. Download the Coinom OpenCart extension package.
2. Log in to your OpenCart admin panel.
3. Navigate to **Extensions → Installer**.
4. Upload the Coinom extension package.
5. Wait for the installation process to complete successfully.
6. Navigate to **Extensions → Extensions**.
7. Select **Payments** from the extension type dropdown.
8. Locate **Coinom** and click **Install**.

## Configuration

<Tip>
  Before configuring the extension, create a merchant and copy the API Key.

  [Create Merchant & Access API Key](https://docs.coinom.com/merchant/create)
</Tip>

1. Navigate to **Extensions → Extensions**.
2. Select **Payments** from the extension type dropdown.
3. Locate **Coinom** and click **Edit**.
4. Enter your **Coinom API Key**.
5. Set **Status** to **Enabled**.
6. Click **Save**.

## You're Ready

Your OpenCart store is now configured to accept cryptocurrency payments through Coinom.

Customers will see Coinom as a payment method during checkout, and orders will be updated automatically once payments are confirmed.
