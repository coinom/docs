## Installation

1. Download the Coinom EDD plugin ZIP file.
2. Log in to your WordPress admin area.
3. Navigate to **Plugins → Add New Plugin**.
4. Click **Upload Plugin**.
5. Select the Coinom EDD plugin ZIP file.
6. Click **Install Now**.
7. Activate the plugin.

## Configuration

<Tip>
  Before configuring the plugin, create a merchant and copy the API Key.

  [Create Merchant & Access API Key](https://docs.coinom.com/merchant/create)
</Tip>

After activating the Coinom plugin:

1. Navigate to **Downloads → Settings → Payments → Gateways**.
2. Enable **Coinom** from the list of available gateways.
3. Open the **Coinom** gateway settings.
4. Enter your **Coinom API Key**.
5. Click **Save Changes**.

## You're Ready

Your Easy Digital Downloads store is now configured to accept cryptocurrency payments through Coinom.

Customers will see Coinom as a payment method during checkout, and orders will be updated automatically once payments are confirmed.
